# Password Policy
**Northlane Systems — IT & Security**
**Effective Date:** September 1, 2025
**Document ID:** IT-SEC-005

## Purpose
This policy establishes minimum requirements for password creation, storage, and rotation across all Northlane systems and applications.

## Password Composition Requirements
All passwords for corporate accounts must:
- Be at least 14 characters long
- Include at least one uppercase letter, one lowercase letter, one number, and one symbol
- Not reuse any of the employee's last 10 passwords
- Not contain the employee's username, first name, or last name

## Multi-Factor Authentication (MFA)
MFA is mandatory for all accounts with access to production systems, customer data, or financial systems. Approved MFA methods include the Northlane Authenticator app and hardware security keys (YubiKey). SMS-based MFA is discouraged and permitted only as a fallback method.

## Password Rotation
Standard user accounts are required to rotate passwords every 180 days. Privileged accounts (system administrators, database administrators, security engineers) must rotate credentials every 90 days.

## Password Managers
Employees are required to use the company-approved password manager (Northlane Vault) for storing credentials related to work systems. Storing passwords in browser autofill, spreadsheets, or plain text files is prohibited.

## Shared and Service Accounts
Shared accounts are discouraged. Where a shared or service account is unavoidable, it must be registered with the Security team, use a randomly generated password of at least 20 characters, and be rotated immediately upon any team member's departure.

## Compromise Response
If an employee suspects their password has been compromised, they must immediately change the password and report the incident to the Security team via the Incident Response process (see IT-SEC-009). Do not wait for confirmation of a breach before rotating credentials.
